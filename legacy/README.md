# Legacy

This folder is not part of the scout.

`polymarket/` is the old paper-trading simulator and Polymarket market reader. It is kept so the history is still in the repo, and it is not imported by the CLI or the site.

`signal_scores/` is the previous 0-100 hand-weighted bet scorer (standings, form, H2H). The live model is the Dixon-Coles score grid plus the Europe-wide Elo in `src/`.
